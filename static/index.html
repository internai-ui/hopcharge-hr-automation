Module 05

Scoring Mode

Choose how candidates are scored. Offline mode (rules engine) requires no API key and scores instantly using the rubrics directly. API mode uses Claude, OpenAI, Google Gemini, or Groq for more nuanced evaluation. Both produce identical output — switch anytime without losing anything.

🤖 ENABLE AI-BASED SCORING (EXTERNAL PROVIDERS)
Off by default. Scoring runs on the offline rules engine only — no API key fields, no external calls. Turning this on reveals the Claude / OpenAI / Gemini / Groq configuration below.

How It Works
📊 Offline Scoring
  • Uses your role rubrics (objective + AI = 100 per role)
  • Concept matching, not keyword-based
  • Paraphrase-robust (same meaning = same score)
  • Honours per-role strictness & creativeness
  • Instant, no latency
🤖 API-Based Scoring
  • LLM reads your rubric guides
  • Understands intent, sarcasm, novel phrasing
  • May score more generously
  • Requires API calls (slight latency)
✓ Switch anytime
Both paths produce identical output. Your evaluations, modal, analytics — all unchanged.

Configuration

Admin Settings

Edit the emails sent at each stage and tune the score thresholds that drive auto-reject and auto-accept. Changes apply to every email and pipeline action from the moment you save.

Score thresholds
Candidates scoring below the auto-reject value are moved to Rejected; those scoring above the auto-accept value are moved into the HR Round.
30
Score 0–100. Anything strictly below this is auto-rejected.
65
Score 0–100. Anything strictly above this is auto-moved to HR Round.
⚠ Auto-reject value should be lower than auto-accept, or candidates in between have no auto-action.

Scoring tuning per role
Tune how the assessment answers are scored for each role. Strictness makes marking harsher or more forgiving. Creativeness controls how much original, unconventional-but-sound answers are rewarded versus standard textbook wording. Both apply in AI and offline modes. Custom traits are qualities the AI should look for, judged by meaning — not keywords: add “high ownership” and the AI rates whether each answer shows ownership, however it’s worded. (Semantic trait judging needs your AI provider key from AI Settings; without a key, strictness and creativeness still apply and traits stay neutral.)
