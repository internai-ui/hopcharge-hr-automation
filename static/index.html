Configure the external AI provider used for intelligent CV parsing. When enabled, uploaded PDFs are parsed via your chosen LLM (Claude, OpenAI, Gemini, Groq, or Hugging Face) for consistent extraction across complex resume layouts. When disabled, the free offline regex+spaCy parser is used.
How It Works
How It Works
Offline Parsing
  • Regex + spaCy section-heading detection
  • Fast and free - no API calls
  • Works well on standard resume layouts
  • Can miss fields on unusual formats, tables, or creative layouts
AI-Based Parsing
  • Routes the extracted text through an LLM for structured extraction
  • Handles arbitrary formats far more consistently
  • Falls back to offline parsing automatically if the call fails
  • Requires an API call (slight latency + cost, per your provider)
✓ Switch anytime
When AI parsing is off or a call fails for any reason, the app always falls back to the offline parser - a resume is never left unparsed.
